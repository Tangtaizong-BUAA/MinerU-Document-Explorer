# 0.5.0 实现与阿里 Live Gate 报告

> 状态：Implemented；Alibaba live gate verified；production rollout pending
> 日期：2026-07-29
> Server/Skill/Schema：0.5.0

## 已落地

- MCP profiles 分为 `project-read / project-contribute / project-resolve / project-ops`；0.4 写工具仅保留 proposal-only shim。
- HTTP principal registry 只保存 token SHA-256、principal ID、profile 与 roles；只有 `project-owner/designated-resolver` 可初始化 `project-resolve`。
- `kb_brief` 强制返回相关开放冲突和 conflict revision；普通成员没有持久解决工具。
- 用户答案通过专用 revision lock 事务写入 resolution、`resolution_pending` conflict 与 ChangePacket；typed resolution 与知识补丁由 Harness 同一 immutable revision 提交。
- canonical 采用 `knowledge/revisions/<revision>` 不可变目录和单 `current-revision.json` 指针；manifest 使用确定性 JSON 与 SHA-256 校验。
- ChangePacket 使用 SQLite WAL 持久队列、幂等键、租约、重试、quarantine/dead-letter。
- MS-Agent 1.6 在隔离 Python Worker 中运行，默认 `qwen3.7-flash`；只暴露 packet-scoped 读取/终止工具，无 Shell、文件系统、SQL、MCP、通用网络或 canonical write 工具。
- 图片与视频使用 OpenAI-compatible content；视频保持 `video_url` 原生输入。关键帧/OCR/转写只作检索和定位辅助。
- `qwen3-vl-embedding` adapter 原生保留 text/image/video 输入并验证向量维度。
- 家庭部署包增加独立 Query Service 与 Maintenance Worker、`ms-agent==1.6.0`、`better-sqlite3`，并生成全文件 SHA-256 清单。

## 已验证

- TypeScript production build 通过。
- 已用独立 Python 3.12 环境真实加载 `ms-agent==1.6.0` 与本地插件，并校验仅注册 9 个受限维护工具；该验证不调用模型、无需 API Key。
- 复用 ArgonType 受管环境中的既有百炼 Key 完成真实调用；Key 明文没有进入命令输出、仓库、知识文档或查询服务。
- `qwen3.7-flash` 文本请求与函数调用通过；模型返回 `finish_reason=tool_calls` 和合法 JSON 参数。
- `qwen3.7-flash` 图片输入通过，合成红色测试图被正确识别；阿里官方公开 MP4 的原生 `video_url` 输入通过并产生 `video_tokens`。
- 完整 `MS-Agent -> 受限工具 -> MaintenancePlan -> Zod validator` 链路通过；原生视频包正确回传 `native_video_evidence_ids`。Live gate 同时修正了 DashScope 配置字段、MS-Agent 标准 system/user 消息、ToolBase 调度、插件单例状态和终止回调。
- `qwen3-vl-embedding` 在同一次调用中为文本、公开图片和官方公开视频返回 3 个 1024 维向量。
- 0.5 contracts、MS-Agent offline protocol、原生视频声明防伪、冲突保护、resolver 权限、SQLite queue、immutable revision、typed conflict transaction、多模态 request adapter 测试通过。
- 项目专项测试在允许 loopback 的环境中通过；完整上游测试在受限沙箱中存在 tsx IPC/HTTP EPERM 与 Metal 模型上下文失败，属于环境门禁，项目专项回归单独在沙箱外复验。
