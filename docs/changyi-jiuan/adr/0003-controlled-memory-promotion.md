# ADR-0003：Agent 记忆采用候选、校验和晋升流程

- 状态：Proposed
- 日期：2026-07-21

## 背景

用户希望 Agent 完成项目工作后通过 MCP 回传，并积累为新的记忆和知识。若 Agent 可直接写入正式记忆，一次误读、无证据推断或过期结论会持续污染未来回答。

## 决策

工作 closeout 和正式记忆分离：

1. Agent 通过 `kb_finish_work` 提交结构化结果；
2. 系统先保存事实性工作记录；
3. 可能复用的内容进入 memory candidate；
4. 依次执行 Schema、来源、判重和冲突检查；
5. 只有策略允许的确定性事实可自动接受；
6. 解释性结论、经验、偏好和取代行为必须审批；
7. accepted 记录通过 disputed/superseded 演进，不静默覆盖。

## 原因

- 阻断 Agent 幻觉的长期放大；
- 将“完成了什么”和“值得记住什么”分开；
- 能保留冲突和历史有效性；
- 支持人工纠正、审计和回滚；
- 允许未来逐步扩大自动采纳范围，而不是首期全开。

## 后果

积极：

- 正式知识可信度更高；
- 失败任务也能诚实积累经验；
- 重试可通过幂等键安全处理；
- 决策变化可以解释。

代价：

- 需要审批队列；
- 候选可能堆积；
- 必须实现冲突和状态检索；
- MCP 本身不能保证 Agent 必然调用 finish，需要 Skill 和完成门禁。

## 自动接受初始边界

仅考虑：

- 文件和哈希验证；
- 测试/构建运行事实及日志引用；
- 合法、无歧义的状态迁移；
- 系统生成的时间与作业事件。

研究结论、人物判断、长期方法和偏好不自动接受。

## 待确认

项目负责人需确认首期是“全部人工审批”还是“允许上述确定性事实自动接受”。
