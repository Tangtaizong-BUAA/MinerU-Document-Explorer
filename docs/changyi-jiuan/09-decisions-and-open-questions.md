# 09 决策与待确认问题

> 状态：Active。这里记录产品层待确认项；代码实现不得偷偷替代用户决策。

## A. 已接受或已由用户明确授权

### D-001：基于 MinerU Document Explorer fork 改造

- 状态：Accepted
- 依据：用户明确要求执行 fork 并开始项目规划文书。
- 影响：保留上游能力，优先组合扩展而非从零重写。
- 记录：[ADR-0001](adr/0001-fork-and-upstream-strategy.md)

### D-002：文书先行

- 状态：Accepted
- 影响：领域、MCP、记忆和验收契约先落地，再开始核心代码修改。

### D-003：遇到实质性不明确问题即时咨询

- 状态：Accepted
- 影响：可逆、安全默认值允许先推进；会改变部署、权限、数据外发或真相源的决定必须询问用户。

### D-004：主要 MCP 客户端

- 状态：Accepted
- 客户端：Qoder、Hermes Agent、Codex；同时保持标准 MCP 兼容，不将领域数据绑定到单一框架。
- 影响：首期以 stdio 为默认传输，以 localhost HTTP 作为多客户端共享模式；三端均需通过 capability、structured output、resource link 和 closeout 互操作测试。

### D-005：Agent 全托管，正常路径零人工介入

- 状态：Accepted
- 依据：用户明确要求系统全托管于 Agent，不要人工介入。
- 影响：摄取、任务回传、记忆判断、冲突处理、重试、重建和健康检查都必须有 Agent 可执行的闭环；不得把“等待人工审批”设计成正常状态。
- 安全边界：正式记忆仍不能由 Agent 任意强制写入，而是由确定性的策略引擎依据证据、来源等级、冲突和有效期自动裁决。无法安全裁决时进入 `quarantined/disputed`，并自动创建补证或修复工作项。
- 记录：[ADR-0004](adr/0004-agent-managed-autonomy.md)

### D-006：历史资料暂缓接入

- 状态：Accepted
- 影响：当前实施先使用合成、脱敏、可公开提交的 fixture 验证 Schema、MCP、幂等、来源和记忆闭环；在真实资料提供前，不宣称真实检索质量或 MinerU 项目语料效果已经通过。

## B. 当前工作默认值

以下尚未被用户逐项确认，只为避免规划停滞：

| ID | 默认值 | 为什么安全 | 改变后的主要影响 |
|---|---|---|---|
| A-001 | 本地优先 | 最少外发和基础设施 | 远程部署需要认证、TLS、对象存储 |
| A-002 | 单机 Agent 服务优先 | 先验证三客户端互操作 | 远程共享需要认证、租约和并发治理 |
| A-005 | 原始资料默认不出本机 | 保护科研与人物资料 | 云 MinerU/模型需资料分类与明确同意 |
| A-006 | 中文为主，英文术语保留 | 符合当前项目语境 | 双语库需语言字段和评测集 |
| A-007 | 先文件＋SQLite，不上图数据库 | 可重建且复杂度低 | Graphiti/Neo4j 需同步和成本治理 |
| A-008 | 源码公开 fork，真实语料不入公开仓库 | 避免资料泄露 | 私有 fork 可调整测试与部署策略 |

## C. 需要用户确认的产品问题

### Q-001：首期协作方式

- 选项：仅本机个人使用 / 同一台机器多人使用 / 局域网或公网远程协作。
- 当前默认：仅本机个人使用。
- 最晚确认：远程 HTTP MCP 或管理界面实施前。
- 影响：认证、权限、部署、备份和审计复杂度。

### Q-002：真实资料的保密等级

- 需要知道：是否包含未公开科研、受访者身份、联系方式、单位内部材料、知情同意限制。
- 当前默认：全部按 `internal`，人物敏感字段按 `restricted`。
- 最晚确认：第一次真实资料 POC 前。
- 影响：云解析、模型选择、日志和公开测试数据。

### Q-003：未来真实资料规模与格式

- 需要知道：大约文件数、总容量、扫描 PDF 比例、图片数量、是否有音视频和 Excel 大表。
- 当前状态：用户暂不提供历史资料；先使用合成 fixture，不扫描任何外部资料目录。
- 最晚确认：第一次真实资料接入前。
- 影响：存储、Git LFS、解析作业并发、模型和备份。

### Q-006：总体信息维护界面

- 选项：Markdown/Obsidian / 本地表格 Web UI / 两者同时。
- 当前默认：文件为真相源，由 Agent 自动生成 Markdown 表格；UI 仅作为可选观察面，不承担必需操作。
- 最晚确认：Phase 2 后半段。
- 影响：前端工作量、双向编辑和冲突处理。

### Q-007：备份目的地

- 选项：外置硬盘 / NAS / 私有对象存储 / 加密云盘 / 组合。
- 当前默认：规划备份接口，不替用户选择物理目的地。
- 最晚确认：Phase 4/6。
- 影响：恢复时间、加密和离机容灾。

### Q-008：Fork 可见性与最终仓库命名

- 当前 fork：`Tangtaizong-BUAA/MinerU-Document-Explorer`。
- 需要确认：长期保持公开 fork，还是未来迁移到私有产品仓库。
- 当前默认：代码 fork 公开，真实数据和密钥永不进入仓库。
- 最晚确认：放入任何组织特有实现或测试材料前。

## E. 决策升级规则

以下变化必须新建 ADR 并由用户确认：

- 原始资料的真相源位置改变；
- 降低自动记忆晋升的证据或冲突门槛；
- 允许数据默认外发云服务；
- 从单机扩展到远程多用户；
- 允许 Agent 物理删除原件、审计或 accepted 历史；
- 取消 Agent 全托管，重新引入必需人工审批步骤；
- 引入第二个不可重建的核心数据库；
- 改变 fork/上游同步策略。
